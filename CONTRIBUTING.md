# Contributing

1. Read `docs/CODING_STANDARDS.md`.
2. Keep behavior in the shared core unless it is genuinely platform integration.
3. Add tests for changed invariants and failure paths.
4. Run format, clippy, and workspace tests before commit.
5. Update documentation in the same logical change when architecture or behavior changes.
6. Keep commits focused and descriptive.

Reference software may inform observable behavior only. Do not submit copied proprietary code or assets.
